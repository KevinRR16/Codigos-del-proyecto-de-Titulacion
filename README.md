Dependencias y Requisitos de Ejecución
Para reproducir el entorno de desarrollo y ejecutar el código del repositorio, se requiere la instalación de Python3.x junto con las siguientes bibliotecas principales:

opencv-python (Procesamiento de imágenes y calibración óptica)

PyQt6 (Renderizado de la interfaz gráfica)

pyserial (Comunicación con el controlador robótico)

numpy (Operaciones matriciales y cálculo de homografías)

Para abrir el programa se tiene que ejecutar el codio GUI_inspeccion_f.py
